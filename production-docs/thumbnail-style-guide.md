# The Last Lantern — Thumbnail & Visual Brand System

## Core system (consistent across all episodes — this is the brand)
- **Palette rule:** one dark base (black/near-black) + exactly ONE desaturated accent color per thumbnail, tied to sub-pillar (see table below). Consistent system, varied composition — not identical layouts.
- **One tension object per thumbnail** — never a cluttered scene. A single lit window, an empty chair, a shadowed figure from behind, one document with a single visible line, a red thread across a map. Pick exactly one per episode.
- **Typography:** one clean, slightly condensed serif or high-contrast sans-serif (Anton/Poppins ExtraBold, already in use, fits this well). No bold red "SHOCKING" tabloid style — wrong register for this brand. Title text on thumbnail: 3–5 words max, a fragment of the hook, not the full title.
- **Composition:** ~60% atmospheric negative space/darkness, ~40% lit subject. This restraint is what reads as "cinematic documentary" rather than "busy clickbait" — and current CTR benchmarking shows restraint outperforming clutter specifically in this niche.
- **Logo placement:** small, same corner, same size every time. This is the ONE thing that should be pixel-identical — it's the actual brand mark, not a content template.

## Per-sub-pillar accent system
| Sub-pillar | Accent color | Typical tension object |
|---|---|---|
| Disappearances | Cold blue-black | Empty chair, single object left behind, a shadowed figure walking away |
| Eerie/forgotten history | Deep red-black | Close-up historical document/artifact, dramatic single-source lighting |
| Abandoned places | Forest green-black | A single lit window in a dark structure, an overgrown doorway |
| Sleep-story retellings | Muted purple-black | Softer focus, one small light source (lantern, lighthouse beam), more negative space than any other category |

## Pre-publish checklist
Before finalizing any thumbnail, confirm:
- [ ] Exactly one clear focal point
- [ ] Only one accent color
- [ ] Someone glancing at it for one second could tell which sub-pillar it belongs to, without reading the title
- [ ] Logo in the same corner, same size as every other thumbnail
- [ ] Text is 3–5 words max and is a fragment of the hook, not the full title

If any answer is no, simplify further — restraint wins in this niche specifically, not more detail.
