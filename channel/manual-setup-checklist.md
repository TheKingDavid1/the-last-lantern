# Manual Setup Checklist — Things Only You Can Do (Day 1–2)

I can't touch your Google/YouTube account directly, so here's exactly what to click through. Should take under 30 minutes total.

## Day 1 — Account setup
- [ ] Create/select the Google account you want to run the channel on (recommend a fresh one, separate from personal, if you don't already have a dedicated one).
- [ ] Create the YouTube channel, name it **The Last Lantern**.
- [ ] Upload `branding/logo.png` as the channel profile picture.
- [ ] Upload `branding/banner.png` as the channel banner (YouTube will let you reposition/crop for safe zones — check it looks right on both desktop and mobile preview).
- [ ] Paste the About description and keywords from `channel-description.md` into Settings → Basic Info.
- [ ] Set the channel handle (try `@TheLastLantern` first, fall back to the alternates listed).
- [ ] Go to Google Account → Security → **turn on 2-Step Verification**. This is required later for YPP eligibility, so do it now and forget about it.
- [ ] Start (don't need to finish) the **AdSense account creation** at adsense.google.com linked to the same Google account — it can sit pending while you build content; you'll link it fully once you apply for monetization.

## Day 2 — Upload defaults (set these once, but re-confirm per video)
- [ ] In YouTube Studio → Settings → Channel → Advanced settings, review the audience default. **Do not rely on a channel-wide "made for kids" setting alone** — confirm "Not Made for Kids" is selected per video at upload time too, since soft/calm content can get flagged by the classifier.
- [ ] Familiarize yourself with the **"Altered or synthetic content"** toggle in the upload flow (Studio → Upload → "Show more" → content disclosure section). Rule of thumb: if imagery or narration could be mistaken for depicting a real event/person as it actually happened, toggle it on. Purely illustrative/stylized art of a historical event generally doesn't need it — when in doubt, disclose.
- [ ] Turn on **Community Guidelines strikes email alerts** (Studio notifications) so you catch any policy notice within a day, not a month.
