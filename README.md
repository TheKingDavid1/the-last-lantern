# The Last Lantern — Production Repo

Working files for **The Last Lantern**, a narrated sleep/mystery-history YouTube channel.

## Structure
- `channel/` — persona ("The Keeper"), channel description, manual account setup checklist
- `production-docs/` — the monetization/niche plan, upload+growth+RPM guide, ChatGPT image prompt library
- `scripts/` — episode scripts + the 10-topic idea bank
- `branding/` — logo, banner
- `thumbnails/` — thumbnail art per episode
- `assets/` — reusable atmosphere image library, per episode/location
- `content/` — narration audio, word-level timing data, caption files (the "recipe" needed to rebuild/edit any episode's video)
- `state-tracking.md` — running production log

## Finished episode videos
Full video files are attached to **GitHub Releases** (not committed directly — see the Releases tab), since they're too large/binary-heavy for normal git history.
